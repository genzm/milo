# 流れ図の配置

`layout=flow` の `@canvas` と `@diagram` は、同じエンジンです。入口は `src/flow/layout.ts` です。diagram の flow は `src/diagram/mount.ts` がキャンバス用のグラフに直し、ここに渡します。自由配置（`layout=free`）は順位を使わず、`src/flow/route-free.ts` だけが線を引きます。

処理は常に同じ順です。

1. 順位（`rank.ts`）
2. 同じ順位の並び（`order.ts`）
3. ノード幅と高さ（`measure.ts`）
4. 座標（`place.ts`）と枝の揃え（`align.ts`）
5. 経路（`route.ts`）
6. 警告（`validate.ts`）

定数は `src/flow/types.ts` の `FLOW` です。希望のノード幅 220、順位の間隔 88、内側の余白 28 などです。

## 順位

辺をたどって、各ノードが何段目かを決めます。循環している辺は戻り線（feedback）にして、順位の計算から外します。自己ループも戻り線です。

残った辺について、始点からの最長経路で段を付けます。どの辺にも入らないノードは先頭の段、循環だけに属するノードは末尾に足します。戻り線の判定のあと、行き先の段が始点以下なら、その辺も戻り線にします。

辺が1本もないときは、書いた順に1段ずつ置きます。

## 並び

同じ段の左右（または上下）の順は、交差を減らすための重心法です。隣の段にある接続先の平均位置で並べ、6回往復します。差が無いときは原稿の順を保ちます。戻り線は並べ替えに使いません。

## 寸法

幅は 180 / 200 / 220 / 260 / 300 から選びます。本文の見出しは最大2行、本文は最大3行に収まる幅を見積もり、同じ段では一番広いノードに揃えます。全体が枠に入らないときは、入る組み合わせを探して点数で選びます。高さのばらつき、希望幅からのずれ、最大高さを小さくする方が高得点です。

`node-width` や個別の `width` / `height` があるノードは、その値を使い、自動の縮小対象にしません。描画時は DOM の実測高さを `atWidth` として渡し、見積もりを上書きします。

## 座標

進行方向を主軸、直交方向を横断軸とします。`direction=right` / `left` なら主軸は横、`down` / `up` なら縦です。段は主軸に並べ、同じ段のノードは横断軸に並べます。全体は枠の中央に寄せ、段が入りきらないときは間隔だけ縮めます。下限は 24px です。

`pinned` の座標と `dx` / `dy` は、並べたあとに足します。

`route=auto` のときは、そのあと枝を揃えます。親子が互いの中央の子であるとき、同じ横断位置にまとめます。偶数分岐で中央が無いノードは、隣り合う2つの中央の中間に置きます。段の中の順は変えません。重なりや逆転が出る結合は捨てます。固定高さに収まらない揃えは行いません。`height=auto` の横流れだけ、高さを足して揃えを残します。`pinned` や `dx` / `dy` がある図では揃えません。

## 経路

`route=auto` は、直列を直線、分岐と合流を共有幹線にします。

分岐は、始点の出口から少し進んだ位置に幹線を置き、そこから各行き先へ Stub を出します。合流は逆です。幹線に乗らない飛び越しは、途中のノードを避ける横断レーンを選びます。1本の辺は `stem`（出口）・`bus`（幹線）・`stub`（入口）に分かれます。矢じりはノード境界の stem / stub にだけ付けます。

`auto` でない辺、戻り線、幹線に乗らなかった辺は、ノード辺上のポートを等分し、`straight` / `curve` / `elbow` で結びます。障害物に当たる曲線は折れ線に落とします。戻り線は進行方向の外側を回ります。

自由配置の曲線は、端点の接線を辺に垂直にせず、短い直線を残してから曲げます。矢じりが接線だけで傾かないためです。

## 警告

| コード | 意味 |
| --- | --- |
| `NODE_OVERLAP` | ノードが重なっている |
| `TEXT_OVERFLOW` | 枠より文字が高い |
| `FRAME_OVERFLOW` | ノードが領域の外に出る |
| `EDGE_COLLISION` | 線が無関係のノードを横切る |
| `EDGE_LABEL_COLLISION` | 線のラベルが重なる |
| `CYCLE_DETECTED` | 循環がある（戻り線で描く。表示する警告からは外す） |
| `INSUFFICIENT_SPACE` | 余白が足りない |

循環そのものは配置を止めません。同じコードの警告は、キャンバス上では先頭の1件だけ出します。
