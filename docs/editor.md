# 編集と発表

生成した HTML をデスクトップ版 Chrome または Edge で開きます。原稿、フォント、描画、編集画面が1ファイルに入っているので、開くのにサーバーは要りません。

## 画面

左がスライド一覧、中央がプレビュー、右が原稿です。一覧ではスライドの追加、複製、削除、前後の移動ができます。新しいスライドは `essay` で入ります。

スライドを開いているとき、右上の「レイアウト」で `cover` / `section` / `lab` / `media` / `essay` を切り替えられます。切り替えると、原稿先頭の `<!-- milo: layout=… -->` を書き換えます。

プレビュー上のチェック項目をクリックすると、原稿の `[ ]` と `[x]` が入れ替わります。画像をダブルクリックすると、埋め込んだ素材を調べられます。発表中はこの操作を止めます。

## 保存

右上の「自動保存を接続」で、その HTML を選び、書き込みを許可します。選んだファイルが milo 形式でないときは接続しません。

右側の原稿を編集すると、入力が止まって約 500ms 後に保存します。入力が続いても、最初の変更から約 2 秒で保存を試みます。`Cmd+S` / `Ctrl+S` は即時保存です。閉じる前に「保存済み」を確認してください。未保存のまま閉じようとすると、ブラウザが確認します。

保存先のファイルが、開いたあと外から変わっているときは衝突として止めます。上書きする前に、画面の案内に従ってください。接続していない編集は、ブラウザ内の下書きに残します。同じ `documentId` の HTML を開き直すと、その下書きを戻せます。

書き戻すのは原稿のブロックです。描画結果の DOM は保存しません。

## 発表

「発表する」、または原稿以外にフォーカスがあるときの `f` で発表画面になります。左右の矢印でスライドを移動し、`Escape` またはもう一度 `f` で戻ります。ダイアログが開いているとき、および入力欄にフォーカスがあるときは、これらのキーは動きません。

## PDF

PDF は編集画面とは別の出力です。作り方は [README](../README.md) の「PDFを同時出力」です。

PDF はスライド 1 枚につき 1 ページで、寸法は `src/slide-size.json` の 1600×900 です。HTML と同じレンダラー、CSS、フォントを使い、編集 UI は含みません。チェックリストは原稿の状態で出ます。基準はコンパイル時点の Markdown で、生成後に HTML 内で編集した内容は反映されません。PDF 出力に失敗しても、生成済みの HTML は残ります。

## キーボード

| キー | 動作 |
| --- | --- |
| `Cmd+S` / `Ctrl+S` | 保存。未接続なら接続を始める |
| `←` / `→` | 前のスライド / 次のスライド |
| `f` | 発表の開始と終了 |
| `Escape` | 発表を終える |
