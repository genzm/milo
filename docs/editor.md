# 編集と発表

生成した HTML をデスクトップ版 Chrome または Edge で開きます。原稿、フォント、描画、編集画面が1ファイルに入っているので、開くのにサーバーは要りません。

## 画面

左がスライド一覧、中央がプレビュー、右が原稿・素材・設定です。一覧ではスライドの追加、複製、削除、前後の移動ができます。削除できるのはスライドが2枚以上あるときです。新しいスライドは `essay` で、見出しは「新しい問い」です。

中央の「変更を見る」は、この HTML を開いたときからの原稿の差分です。件数はボタンの横に出ます。自動保存したあとも、開いたときとの差は残ります。

右は「原稿」「素材」「設定」の3つです。

- 原稿では、そのスライドの Markdown を編集します。見出しの「レイアウト」で `cover`（表紙）/ `section`（章扉）/ `lab`（実験）/ `media`（メディア）/ `essay`（文章）を切り替えられます。切り替えると、原稿先頭の `<!-- milo: layout=… -->` を書き換えます。
- 素材では、埋め込んだ画像のプレビュー、容量、参照 ID を見られます。差し替え、このパネルへのドロップ、現在のスライドへの挿入ができます。追加できるのは 12MB 以下の GIF、PNG、JPEG、WebP、SVG です。SVG は外部参照とスクリプトを含まないものに限ります。
- 設定は文書の JSONC です。`title` を持ちます。

プレビューは、原稿の入力が止まって約 220ms 後に更新します。チェック項目をクリックすると、原稿の `[ ]` と `[x]` が入れ替わります。`::image` の画像をダブルクリックすると、素材タブでその画像を開きます。発表中はこの操作を止めます。

## 保存

右上の「自動保存を接続」で、その HTML を選び、書き込みを許可します。選んだファイルが milo 形式でないときは接続しません。

右側の原稿を編集すると、入力が止まって約 500ms 後に保存します。入力が続いても、最初の変更から約 2 秒で保存を試みます。`Cmd+S` / `Ctrl+S` は即時保存です。未接続のときは、この操作が接続を始めます。閉じる前に「保存済み」を確認してください。未保存のまま閉じようとすると、ブラウザが確認します。

表示は「保存済み」「保存中…」「未保存の変更」「外部変更で停止」「許可が必要」「保存できません」です。未接続で編集があるときは「未接続 · 未保存」です。一度接続したファイルを覚えているときは、ボタンが「自動保存を再接続」になります。

保存先のファイルが、開いたあと外から変わっているときは衝突として止めます。「ファイルを読み直す」は、画面の未保存の変更をブラウザへ退避してから、ディスクの内容を読み込みます。許可が切れたときは「許可して再開」、書き込みに失敗したときは「再試行」です。接続していない編集は、約 150ms 後にブラウザ内の下書きへ残します。タブを隠したときも、下書きと未保存の書き込みを試みます。同じ `documentId` の HTML を開き直すと、その下書きを戻せます。

書き戻すのは原稿のブロックです。描画結果の DOM は保存しません。

## 発表

「発表する」、または原稿以外にフォーカスがあるときの `f` で発表画面になります。ボタンは「編集に戻る」に変わります。左右の矢印でスライドを移動し、`Escape`、もう一度 `f`、または「編集に戻る」で戻ります。ダイアログが開いているとき、および入力欄にフォーカスがあるときは、これらのキーは動きません。編集中のプレビューは原寸までで、窓が狭いときは縮小します。発表中は画面いっぱいに合わせます。

## PDF

PDF は編集画面とは別の出力です。作り方は [README](../README.md) の「PDFを同時出力」です。

PDF はスライド 1 枚につき 1 ページで、寸法は `src/slide-size.json` の 1600×900 です。HTML と同じレンダラー、CSS、フォントを使い、編集 UI は含みません。チェックリストは原稿の状態で出ます。基準はコンパイル時点の Markdown で、生成後に HTML 内で編集した内容は反映されません。PDF 出力に失敗しても、生成済みの HTML は残ります。

## キーボード

| キー | 動作 |
| --- | --- |
| `Cmd+S` / `Ctrl+S` | 保存。未接続なら接続を始める |
| `←` / `→` | 前のスライド / 次のスライド |
| `f` | 発表の開始と終了 |
| `Escape` | 発表を終える |
